# Каталог промптов проекта (Prompts Management)

> **Назначение каталога:**  
> Данная папка является централизованным хранилищем всех промптов, требований, дизайн-брифов и системных инструкций для искусственного интеллекта.  
> Она гарантирует воспроизводимость разработки, прозрачность архитектурных решений и защиту от потери ключевых идей.

---

## 📁 Структура каталога и что в него складывать

```
prompts/
├── README.md                  # Данное руководство по работе с промптами
├── 01-product-ideation/       # Продуктовые и концептуальные промпты
│   └── template-prd.md        # Шаблон формирования требований к продукту
├── 02-ui-ux-design/           # Промпты для дизайн-системы, арта и интерфейсов
│   └── template-ui-prompt.md  # Шаблон промпта на генерацию UI и дизайн-токенов
├── 03-runtime-ai/             # Промпты для встроенного ИИ в приложении (если есть)
│   └── template-system-prompt.md # Шаблон системного промпта со строгим JSON-ответом
└── 04-task-instructions/     # Инженерные промпты для AI-агентов (Antigravity, Claude)
    └── template-task-brief.md # Шаблон технического задания на разработку фичи
```

---

### 1. `01-product-ideation/` (Продуктовые концепты и User Stories)
- **Что сюда складывать:**
  - Исходные идеи и описание проблемы пользователей.
  - Сгенерированные или согласованные Product Requirements Documents (PRD).
  - Описания сценариев взаимодействия (User Stories, Job Stories, Use Cases).
  - Списки фичей (Feature Lists) и скоуп релизов (MVP vs Post-MVP).
- **Зачем:** Чтобы любой AI-ассистент в новом чате мог мгновенно прочитать этот каталог и понять бизнес-логику без долгих объяснений.

---

### 2. `02-ui-ux-design/` (Дизайн, макеты и визуальные промпты)
- **Что сюда складывать:**
  - Промпты для генерации концептов интерфейсов и арт-листов (Midjourney, Imagen, DALL-E, Gemini).
  - Цветовые палитры, дизайн-токены (HEX, RGB, типографика).
  - Описания тактильных ощущений, анимаций (60 FPS, micro-interactions, haptics).
  - Скриншоты и концепт-листы (как в `dark_ui_variants_sheet_*.png`).

---

### 3. `03-runtime-ai/` (Промпты выполнения внутри приложения)
- **Что сюда складывать:**
  - Если ваше приложение внутри себя использует LLM (AI-тьютор, умный поиск, суммаризация, генерация кода/текста):
    - Системные промпты (System Instructions).
    - Few-shot примеры (входные и идеальные эталонные выходные данные).
    - Схемы структурированного вывода (JSON Schema для Structured Outputs).
    - Политики безопасности и фильтрации галлюцинаций.

---

### 4. `04-task-instructions/` (Технические задания для AI-агентов)
- **Что сюда складывать:**
  - Промпты-задания, которые вы даете ассистенту в Antigravity/Cursor/Claude для реализации крупных модулей.
  - Планы сложных рефакторингов.
  - Пошаговые сценарии тестирования и отладки.

## 🎯 Стандарты хорошего промпта (Golden Rules)
1. **Четкая роль:** «Ты ведущий архитектор...» или «Ты эксперт по эргономичному мобильному UI...».
2. **Контекст и ограничения:** Обязательно указывать стек, версии и запреты (например: «Никаких внешних тяжелых библиотек», «Только чистый CSS»).
3. **Формат результата:** Требовать конкретный структурированный результат (markdown-таблица, JSON-схема, готовый файл с JSDoc).
4. **Критерии приемки:** Что считается успехом выполнения (тесты проходят, нет ошибок сборки, соблюдена контрастность WCAG AA).
