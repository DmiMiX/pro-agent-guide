# Шаблон дизайн-промпта (UI/UX Concept Prompt)

## Роль
Ты признанный арт-директор и ведущий UI/UX дизайнер мобильных и веб-интерфейсов.

## Задача
Сформировать спецификацию дизайн-системы и визуальный стиль для экрана: [Название экрана].

## Входные параметры стиля:
- **Атмосфера:** [Например: Dark Fantasy, Minimalist High-Tech, Neo-Brutalism, Clean Corporate]
- **Базовая палитра:**
  - Background (основной фон)
  - Surface (фон карточек/панелей)
  - Accent / Primary (акцентный цвет кнопок и интерактива)
  - Text Primary (высококонтрастный текст)
  - Secondary / Muted (пояснения)
- **Эргономика:**
  - Touch targets >= 44x44px.
  - Safe area insets (отступы под вырезы и жесты).
  - Контрастность текста по WCAG AA (текст > 4.5:1, заголовки > 7:1).
